# i18n

- Default locale: **`en`**. Optional: **`vi`**.
- Cookies (separate on purpose):
  - `eve_guest_locale` — `/chat` + `/b/[slug]` only
  - `eve_dashboard_locale` — dashboard operator UI only
- Never write the guest cookie from dashboard Settings (or vice versa).
- Agent default language follows guest locale via header `x-eve-locale` → auth attribute `locale` in `agent/channels/eve.ts` / `agent/instructions.ts`. Still follow the guest's message language if it differs.
- Product chrome strings → `messages/en.json` + `messages/vi.json` via `next-intl` / `createTranslator`.
- FAQ / workspace profile text in DB is **not** auto-translated.
